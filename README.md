# LLZTO First-Principles Raman Analysis

This repository contains reconstructed analysis notebooks, processed data, and documentation for studying how Li concentration affects first-principles calculated Raman spectra of Ta-doped LLZO/LLZTO garnet solid electrolytes.

The project focuses on post-processing and interpretation of saved phonon and Raman calculation outputs, including phonon density of states, projected vibrational-mode analysis, and broadened Raman spectrum comparison across different Li contents and molecular dynamics snapshot times.

## Project scope

The original research project investigated Li-deficient Ta-doped LLZO-type structures with nominal compositions:

| Label | Nominal composition |
|---|---|
| `Li6p5` | Li6.5La3Zr1.5Ta0.5O12 |
| `Li5p5` | Li5.5La3Zr1.5Ta0.5O11.5 |
| `Li5`   | Li5La3Zr1.5Ta0.5O11.25 |

For each Li content, processed data are organized for structures sampled from molecular dynamics at:

50 ps
75 ps
100 ps


## Scientific goals

The analysis focuses on:

comparing calculated Raman spectra for different Li concentrations;
identifying frequency regions associated with Li–O vibrational modes;
using phonon density of states and projected mode analysis to support Raman peak interpretation;
examining the effect of MD snapshot time on calculated Raman spectra;
documenting a reconstructed first-principles Raman workflow for LLZTO garnets.
